# Taskelio 0.1.0 — primeira versão pública

Extensão open source para Chrome e Edge que conta atividades de trabalho usando regras configuráveis.

## Baixar e instalar

1. Baixe **taskelio-v0.1.0.zip** na seção **Assets** desta página.
2. Extraia o ZIP para uma pasta permanente.
3. Abra `chrome://extensions` ou `edge://extensions` e ative **Modo do desenvolvedor**.
4. Clique em **Carregar sem compactação** / **Carregar expandida** e selecione a pasta que contém `manifest.json`.
5. Abra o Taskelio pelo menu de extensões e clique em **Abrir meu painel**.

Não é necessário instalar Node.js ou executar comandos. O arquivo “Source code” é o projeto completo; para instalar a extensão diretamente, prefira o ZIP **taskelio-v0.1.0.zip**.

## O que está incluído

- Regras por site e caminho.
- Gatilhos para mudança de campo, clique e abertura de página.
- Seleção visual e teste de elementos.
- Controle de duplicação por item ou por dia.
- Metas, totais, média por dia ativo e popup de acompanhamento.
- Histórico, ajustes manuais e exportação CSV.
- Ícone próprio, dados locais e licença MIT.

Leia o [guia de uso](https://github.com/blajeen/taskelio/blob/main/docs/USAGE.md).

## Limites desta versão inicial

A captura foi testada em Chromium com páginas simuladas. É necessário validar cada regra no sistema real. Ainda não há conectores específicos, suporte a Excel desktop, iframes, sincronização ou atualização automática. Cliques representam intenção, não confirmação de sucesso. Para acompanhar conclusão, prefira uma mudança de campo visível.
