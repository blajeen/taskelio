# Taskelio 0.2.0 — English + Português

## English

Taskelio now supports English and Portuguese in the dashboard, popup, rule editor, visual picker, feedback messages and CSV exports.

- Choose **English** or **Português** using **Language / Idioma** in the dashboard or popup.
- Your preference is saved locally and shared between extension pages.
- The first launch uses Portuguese for Portuguese browser locales and English otherwise.
- Existing counters, rules, expected values and history are preserved. User-created names are not translated.
- [English README](https://github.com/blajeen/taskelio/blob/main/README.en.md) and [user guide](https://github.com/blajeen/taskelio/blob/main/docs/USAGE.en.md) are available.

Download **taskelio-v0.2.0.zip** under **Assets**, extract it and load the folder containing `manifest.json` using **Developer mode → Load unpacked** at `chrome://extensions` or `edge://extensions`.

**Updating from 0.1.0:** replace the files in the same folder and click **Reload** on the browser’s extensions page, then reload your work website tabs. Do not uninstall if you want to retain local data.

## Português

A extensão agora tem inglês e português no painel, popup, editor de regras, seletor visual, mensagens e exportação CSV.

Troque o idioma em **Idioma / Language**. Sua preferência fica salva no navegador. Contadores, regras, valores esperados e histórico são preservados; os nomes criados por você não são traduzidos.

Baixe **taskelio-v0.2.0.zip** em **Assets**. Para atualizar da versão 0.1.0, substitua os arquivos na mesma pasta e clique em **Recarregar** na página de extensões. Depois recarregue as abas do sistema de trabalho. Evite desinstalar para preservar seus dados locais.

Leia o [guia de uso](https://github.com/blajeen/taskelio/blob/main/docs/USAGE.md).
